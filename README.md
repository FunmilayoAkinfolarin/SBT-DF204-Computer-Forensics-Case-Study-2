# SBT-DF204 Computer Forensics – Case Study 2

## Reconstructing Suspected Drug Trafficking From Chrome Web History

This case study involved the forensic examination of a Google Chrome History database to reconstruct browser activity relevant to a suspected drug-trafficking investigation.

### Tools Used

* Kali Linux
* SQLite3
* SHA-256
* SQL queries

### Analysis Covered

* Chrome browser history
* Craigslist posting activity
* Gmail activity
* Download records
* Bitcoin-related activity
* Kraken-related activity
* Browser search terms
* Timeline reconstruction

### Evidence

The analysis was performed on the supplied Chrome `History` database. The evidence and working copies were verified using SHA-256 hashing.
